---

## 🗄️ Βάση Δεδομένων (SQLite)

Το αρχείο `superleague.db` δημιουργείται αυτόματα στον ίδιο φάκελο.

### Πίνακες

| Πίνακας | Περιγραφή |
|---|---|
| `teams` | Ομάδες (όνομα, πόλη, γήπεδο, έτος ίδρυσης) |
| `seasons` | Σεζόν (π.χ. 2024-2025) |
| `matchdays` | Αγωνιστικές ανά σεζόν |
| `matches` | Αγώνες (ομάδες, σκορ, ημ/νία, διαιτητής) |
| `referees` | Διαιτητές (όνομα, χώρα, σήμα) |
| `players` | Παίκτες (πλήρες προφίλ) |
| `rosters` | Ρόστερ ανά ομάδα/σεζόν |
| `coaches` | Προπονητές |
| `team_coaches` | Ιστορικό προπονητών ανά ομάδα/σεζόν |
| `player_match_stats` | Στατιστικά παικτών ανά αγώνα |
| `match_events` | Γεγονότα (γκολ, κάρτες, αντικ/σεις) |
| `standings` | Βαθμολογία (αυτόματη ενημέρωση) |

---

## 📥 Import από CSV

Δημιουργήστε ένα CSV με τις εξής στήλες:

```
home_team,away_team,date,home_score,away_score,status
Ολυμπιακός,ΑΕΚ,2025-01-10,2,1,played
ΠΑΟΚ,Παναθηναϊκός,2025-01-11,0,0,played
```

Στη σελίδα **Import** επιλέξτε σεζόν και φορτώστε το αρχείο.

---

## 🔧 Χειροκίνητη χρήση της βάσης

```python
from database import get_connection, MatchDAO, StandingsDAO

# Καταχώρηση αγώνα
MatchDAO.insert(season_id=1, matchday_id=1,
                home_team_id=1, away_team_id=2,
                match_date="2025-01-15",
                stadium="Γ. Καραϊσκάκης",
                home_score=3, away_score=1,
                status="played",
                referee_id=1,
                attendance=30000, notes="")

# Επανυπολογισμός βαθμολογίας
StandingsDAO.recalculate(season_id=1)
```

## 📊 Ενότητες Εφαρμογής

- **Dashboard** — Σύνοψη και τελευταίοι αγώνες
- **Αγώνες** — Καταχώρηση, αποτελέσματα, φίλτρα ανά αγωνιστική
- **Βαθμολογία** — Live βαθμολόγιο με χρωματική διαβάθμιση
- **Ομάδες** — CRUD ομάδων
- **Παίκτες** — Πλήρες μητρώο παικτών με αναζήτηση
- **Ρόστερ** — Ρόστερ ανά ομάδα και σεζόν (+ δανεικοί)
- **Προπονητές** — Μητρώο + ανάθεση σε ομάδα/σεζόν
- **Διαιτητές** — Μητρώο με χώρα και επίπεδο σήματος
- **Στατιστικά** — Top scorers, assists, κάρτες ανά σεζόν
- **Import** — Εισαγωγή αγώνων από CSV
